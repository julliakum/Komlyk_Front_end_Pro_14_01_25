# Rozetka Admin Panel
Це адмін-панель для керування продуктами, натхненна дизайном Rozetka.

## 📦 Структура проєкту
HW46/
rozetka-admin/
├── client/ – фронтенд (React + Redux)
└── server/ – бекенд (Node.js + Express)


## 🚀 Як запустити

## 1. Запуск клієнта (frontend)

```bash
cd HW46/rozetka-admin/client
npm install
npm run dev

Інтерфейс буде доступний за адресою: http://localhost:5173

## 2. Запуск сервера (backend)

cd HW46/rozetka-admin/server
npm install
npm run dev
