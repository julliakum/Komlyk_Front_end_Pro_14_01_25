# React + Vite

React-додаток, створений з використанням [Vite](https://vitejs.dev/).

Додаток складається з трьох блоків:
- Хедер (Header)
- Ліва бічна навігація (Sidebar)
- Центральний контейнер (MainContent)


## Як запустити додаток:

1. Перейдіть в папку проєкту:

cd HW39-react\vite-project

2. Встановіть залежності:

npm install

3. Запустіть локальний сервер розробки:

npm run dev

4. Відкрийте браузер і перейдіть за посиланням:

http://localhost:5173# Front-end-Pro
