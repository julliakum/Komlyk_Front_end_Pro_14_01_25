React + Vite React-додаток, створений з використанням Vite.

Як запустити додаток:

Перейдіть в папку проєкту:

cd HW40\todo-list

Встановіть залежності:

npm install

Запустіть локальний сервер розробки:

npm run dev

Відкрийте браузер і перейдіть за посиланням:

http://localhost:5173

Для авторизації (логін та пароль):

admin
